# 创新药—CRO 板块轮动交易策略：回测代码与复现数据

本仓库是课程论文《**创新药与 CRO 板块轮动交易策略设计与回测研究**》的配套代码与结果数据，供审稿、复现与查验使用。

仓库地址：https://github.com/wszsdr/innovative-drug-cro-rotation

论文以 A 股创新药与 CRO 两个子板块为对象，构建由**动量选择、趋势过滤、波动率控制、可辨识度自适应**四部分组成的板块轮动策略，并以固定参数规则、逐月滚动训练的机器学习方向预测、逐年滚动校准参数三种方案并列对照，在 2019 年 7 月 29 日至 2026 年 10 月 15 日共 1748 个交易日的日频数据上完成回测。

> 仓库不含投机建议。所有结果均为历史回测，不构成任何投资建议。

## 二、环境要求

**仅依赖 Python 标准库**，无需安装 pandas、numpy、scikit-learn 等任何第三方包。

- Python ≥ 3.9（开发时使用 3.13.12）
- 逻辑回归、bootstrap、Newey-West 等均为脚本内手写实现，便于逐行核查

## 四、回测口径要点

| 项目 | 设定 |
|---|---|
| 样本区间 | 2019-07-29 至 2026-10-15，共 1748 个交易日；前 120 个交易日为信号预热期，不计入净值 |
| 样本划分 | 2023-01-01 之前为样本内，之后为样本外 |
| 板块组合 | 两个子板块各 6 只成分股，等权、月末再平衡，再平衡换手按单边 0.1% 在净值中内扣 |
| 信号与执行 | 第 t 日收盘后计算信号，最早第 t+1 日执行；调仓频率月度 |
| 交易成本 | 单边 0.1%，敏感性区间 0.05%—0.3% |
| 杠杆与卖空 | 不使用 |
| 无风险利率 | 2%（夏普比率计算） |

**防未来信息约束（六条）**：信号与收益不同期重叠；成分股名单期初固定；再平衡成本与换仓成本分别计入；不使用公告日前不可得的财务/新闻/分析师数据；机器学习模型只用已实现标签训练、扩展窗口推进；不使用回测时点之后才确定的指数成分。

## 五、主要结果（全样本）

| 组合 | 年化收益 | 年化波动 | 夏普比率 | 最大回撤 | Calmar |
|---|---:|---:|---:|---:|---:|
| S1 动量轮动 | 25.03% | 38.45% | 0.60 | -52.24% | 0.48 |
| S2 动量+趋势 | 16.98% | 34.63% | 0.43 | -45.89% | 0.37 |
| **S3 动量+趋势+波动率** | 9.36% | 15.40% | 0.48 | -21.52% | 0.43 |
| S4 波动率目标 25% | 12.23% | 24.06% | 0.43 | -33.48% | 0.37 |
| **S5 自适应轮动** | **14.13%** | 18.14% | **0.67** | -31.61% | 0.45 |
| S6 机器学习方向预测 | 3.17% | 17.45% | 0.07 | -36.88% | 0.09 |
| S7 滚动参数校准 | 5.03% | 15.47% | 0.20 | -37.87% | 0.13 |
| B1 创新药买入持有 | 10.24% | 30.94% | 0.27 | -49.83% | 0.21 |
| B2 CRO 买入持有 | 16.92% | 44.49% | 0.34 | -79.43% | 0.21 |
| B3 静态 50/50 | 15.17% | 34.19% | 0.39 | -60.24% | 0.25 |
| B4 沪深300 | 1.13% | 18.62% | -0.05 | -45.60% | 0.02 |

**结论强度的三个限定**（详见论文第 3.6—3.7 节）：

1. bootstrap 置换检验（持仓段随机重排 1000 次）中，S5 夏普位于 94.9% 分位（p≈0.05）；
2. 7 个策略经 Bonferroni 校正（阈值 0.05/7≈0.0071）后无一显著；
3. 机器学习模型 63 期预测的样本外方向准确率 52.3%（p=0.88），与抛硬币无显著差异。

## 六、已知局限

- 成分股按事后可见的龙头名单固定选取，**幸存者偏差未完全消除**（论文 3.8 节用中证创新药产业指数 931152 作替代标的检验，排序一致但未根治）；
- 未引入流动性约束、涨跌停不可交易、冲击成本等 A 股微观结构限制；
- bootstrap 采用持仓段随机重排而非分块自助法，对时序相关性的处理属简化；
- `创新药CRO轮动策略回测报告.html` 为 v1 口径产物，数字与论文 v2 口径不一致。
